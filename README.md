# capsla.app

Сайт [Capsla](https://capsla.app). Публикуется корень ветки `main`: Cloudflare (Workers Builds) выкладывает его за полминуты после пуша. Шага сборки на стороне Cloudflare нет, поэтому собранные страницы коммитятся вместе с исходниками.

## Что собирается, а что написано руками

| Путь | Откуда |
|---|---|
| `/`, `/<язык>/` — главная на 17 языках | `node build.mjs` из `src/home.html` и `i18n/<язык>.json` |
| `/press/`, `/ru/press/` — для прессы | `node build.mjs` из `src/press.html` и ключа `press` в `i18n/en.json`, `i18n/ru.json` |
| `/assets/` — стили, скрипт, шрифт цифр, значки App Store | `node build.mjs`, с отпечатком содержимого в имени (кэш на год) |
| `sitemap.xml` | `node build.mjs` |
| `/{ru,en,de}/privacy/`, `/{ru,en,de}/support/` | написаны руками, на `styles.css` и `app.js` |

**Адреса страниц политики и поддержки не менять:** на них ссылаются приложение и App Store Connect.

## Как править

1. Тексты — в `i18n/<язык>.json`, никогда в собранном HTML. Разметка — `src/home.html`, `src/press.html`, оформление — `src/home.css`, таймер и фон — `src/home.js` и `src/orbital.js`.
2. `node build.mjs` — пересобирает всё и печатает вес страниц.
3. Проверить локально: `python3 -m http.server 8792` в корне и открыть `http://localhost:8792/ru/`. Параметр `?speed=60` ускоряет пробный таймер, чтобы увидеть смену фаз.
4. Закоммитить исходники вместе с собранным и отправить в `main`. Статус выкладки — проверка «Workers Builds: capsla» на коммите в GitHub.

Язык включается сам, как только появляется `i18n/<код>.json` со всеми ключами `en.json` (сборка падает на недостающем ключе). Список языков и их названия — `LANGS` в `build.mjs`; арабский собирается с `dir="rtl"`, поэтому в CSS только логические свойства (`inline-start`/`inline-end`).

## Чего не делать

- **Не отправлять на GitHub рабочие ветки.** Локально можно работать в ветке, но наружу уходит только `main`.
- **Не класть крупные файлы.** Архивы по 16–17 МБ уронили выкладку, хотя предел Cloudflare формально 25 МБ; архивы для прессы держим около 3 МБ (скриншоты в JPEG).
- **Не трогать почтовые записи DNS** (MX, SPF, DKIM, DMARC): на них работает Email Routing для `support@`, `privacy@` и `press@`.
- **Не обещать на сайте больше, чем делает приложение:** факты сверять с описанием версии в App Store.

## Откуда материалы

- Фон «Орбиты» в `src/orbital.js` — перенос `OrbitalBackground.metal` и `OrbitalFrameResolver.swift` из приложения, числа те же.
- Шрифт цифр — Big Shoulders Display Medium (OFL), урезан до цифр и двоеточия.
- Значки App Store — официальные, с `toolbox.marketingtools.apple.com`; для украинского, арабского и хинди у Apple своего значка нет, стоит английский.
- Скриншоты статистики — из отладочной сборки приложения с тестовой историей (`-UITestSeedStatistics -UITestScreen statistics-week`); кадры для прессы и блокировки — из App Store Connect.
